# 運ゲーート (Unge-Gate)

確率で進む3Dゲートゲームです。PC・スマホ両対応、三人称視点で動かせます。

## 遊び方
- 手前 **80%** → 中間 **50%** → 最後 **10%** の順にゲートをくぐります。
- 成功で次の段へ、失敗で最初の位置に戻ります。10%を突破するとクリアです。
- PC: WASD / 矢印キーで移動、クリックしてマウスで視点操作（Escで解除）
- スマホ: 左下のジョイスティックで移動、画面ドラッグで視点操作
- 拡大・縮小: マウスホイール、スマホは2本指のピンチ操作（⚙のスライダーでも調整可）
- 右上の ⚙ から画面の向き（自動/横/縦）、視点の感度、ズーム、上下反転を設定できます。

## 起動方法
`index.html` をブラウザで開くだけで動きます（three.js を内蔵しているのでオフラインでも動作）。

### GitHub Pages で公開する場合
1. このファイル一式をリポジトリに push
2. Settings → Pages → Branch を `main` / `(root)` にして保存
